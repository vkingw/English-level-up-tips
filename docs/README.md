# 人生进阶指南

中文 | [English](en/)

[![GitHub stars](https://img.shields.io/github/stars/byoungd/up?style=flat&logo=github&label=Stars)](https://github.com/byoungd/up) [![Content license](https://img.shields.io/badge/content-CC%20BY--NC%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc/4.0/)

有些人把成长写成一张越来越长的清单：更多单词、更多课程、更多工具，更多被收藏却从未抵达生活的答案。真正的变化却常常发生在另一处：你终于听懂一段话，写完一封重要的邮件，在陌生的对话里说清自己的意思，或者在一段失序的日子里重新辨认出自己。

这是一张为长期成长绘制的地图。它从 2017 年的《离谱的英语学习指南》出发，沿着英语学习，走向 AI 学习、工作能力、人生复盘、创业与恢复。它不许诺捷径，也不把某个人走过的路装扮成人人适用的真理；它只邀请你把愿望带回现实，把现实留下证据。

我是韩先凯，也叫离谱。如今，我在维护这份开放内容项目的同时，出任中国词元云计算有限公司董事长，继续验证一条更长的路径：**学习 AI → 使用 AI 开发项目 → 建设 AI 资源层产品 → 验证企业服务与商业模型**。身份与商业关系会被写在明处，收入结果则只由可核验的事实证明。

我们反复练习同一个循环：**诊断现状 → 选择任务 → 主动练习 → 获得反馈 → 留下证据 → 调整下一步**。成长不是把日历填满，而是让下一次行动比上一次更接近真实目标。

这里的文字也会尽量标明自己的来处：

- **研究结论**：给出来源，并说明证据能覆盖到哪里；
- **个人经验**：保留故事的温度，但不把它冒充成普遍处方；
- **待验证假设**：把不确定性写在纸上，交给下一轮行动检验。

## 从今天的一个动作开始

不要先等一套完美计划。先为眼前的生活找一个足够小、却可以留下痕迹的动作：

1. 用 [英语能力诊断](templates/english-diagnostic.md)，或一项真实工作任务，找到今天的起点。
2. 把目标、基线、证据和下一步写进 [学习状态](templates/learning-state.md)，让未来的自己不必从雾里醒来。
3. 只选一个 25–45 分钟的任务，完成一个可检查的输出，暂时把继续搜集资料的冲动放下。
4. 一周后用 [每周复盘](templates/weekly-review.md) 回看证据，再决定下一步是加深、放慢，还是换一条路径。

## 英语学习系统：把“想会”变成“能做”

先读 [CEFR 目标与自测](threads/part-1/0-cefr.md)。英语水平不应只是一串模糊的词汇量，也不应被一张旧试卷永久定格；更可靠的问法是：在真实场景里，我现在能完成什么？

沿着下面的路径前进，每一站都留下可以回看、比较和修订的证据：

## AI 学习与工作：让工具退回工具的位置

[使用 AI 学习一切](threads/part-3/1-ai-learning.md)并不从“哪个工具最好”开始，而从“我此刻要完成什么”开始：

- 需要循序提问、脚手架和知识检查时，使用带引导的对话；
- 需要长期保存材料、作品、错误与上下文时，使用项目空间，并维护本地状态文件；
- 需要有来源的研究时，优先选择能回到原始材料的检索工具或资料库；
- 需要最终交付时，由人定义标准、核对事实，并承担最后的判断责任。

产品会变化，方法应当能够迁徙。涉及 ChatGPT、Gemini、Claude、NotebookLM、Perplexity、DeepL 等产品的说明，会标明核验日期、地区或套餐限制和官方来源；工具排名不会成为这份地图的中心。

当学习进入真实项目，下一步不只是“让 AI 写代码”，而是建立一条可复查的开发链，并回答资源、权限、成本、部署和持续服务如何落地。[AI 学习、项目开发与资源层创业](threads/part-3/2-ai-development-and-resource-layer.md)记录了我以韩先凯和中国词元云董事长身份正在推进的实践：从 AI 辅助开发走向多模型接入、路由、计量、治理与企业交付。

这条业务路径已经形成明确的产品与服务方向，但没有在本项目中被写成收益神话。专题会讨论客户为什么付费、服务如何验收、成本如何覆盖，以及哪些结果仍需真实项目和长期数据验证。

## 进步，不由时长证明

学习时长可以记录你坐在桌前多久，却不能替你回答是否真的更自由。每周至少回看四类证据：

- **完成**：是否完成了计划中的真实任务；
- **质量**：正确率、可理解度、结构、流利度或外部反馈是否改善；
- **保持**：隔几天后，能否主动回忆并再次使用；
- **迁移**：能否把所学带到新材料、新对话或真实工作里。

当表现稳定提高时，增加间隔或难度；当同一种错误反复回来时，缩小任务、补足先修知识并增加反馈。计划应当服务于表现，而不是让表现服从日历。
